# xbox-mc

Minecraft Java Edition running natively on an Xbox One, as a UWP app in Developer Mode.

The app has its own launcher: sign in with your Microsoft account, pick a version and press play. It checks that the account owns Minecraft Java, downloads the game from Mojang and starts it with Fabric and a few performance mods. Nothing from Minecraft ships with the app.

Versions right now: 1.17.1 and 1.21.11.

It's a hobby project and still rough. You need your own Xbox in Developer Mode and your own copy of Minecraft Java.
